# 01 — When to add weight — the app decides

*Kiedy dołożyć ciężaru — decyduje aplikacja*

| | |
| --- | --- |
| **Need** | „Nie wiem, kiedy dołożyć ciężaru” — I never know when it's time to go heavier |
| **Persona** | Gym regular, 7 weeks into a plan, stuck at the same weights for months before. |
| **Problem** | Most people repeat the same weights for months: going heavier too early hurts, too late wastes the work. Spreadsheets and memory do not tell you when. |
| **How the app helps** | Every set comes pre-filled with today’s target. After the last set the app asks how much was left in the tank and decides: more reps, or a heavier weight — first in one set only, so the jump is safe. |
| **Key message** | Robisz serie. Aplikacja decyduje, kiedy ciężej. — *You do the sets. The app decides when to go heavier.* |
| **Screens shown** | Dziś (today’s planned session) · Guided session: set, rest timer, effort question · Session summary |
| **App time in the take** | 2026-10-15 18:20:00+02:00 (Europe/Warsaw) |

## Post-production

- **Hook (0–3 s):** „Kiedy dołożyć ciężaru?” — *When should you go heavier?*
- **Closing card (last 2–3 s):** „GYM TRACKER — progres bez zgadywania” — *GYM TRACKER — progress without guesswork*
- **Music:** Driving, confident electronic beat around 110 BPM; a short riser under the summary at the end.
- **Length:** keep the edit between 25 and 45 s. Cut inside a beat, never across a tap, so every action keeps its cause and its result.
- **Style:** see the shared guide in [README.md](README.md#post-production-guide).
