# Contact button („Kontakt”) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
> Executed inline in the planning session (the user is away and asked for an autonomous finish).

**Goal:** A contact button next to „Napisz do autora” with Instagram, the Polish Discord server
and a support link chosen by country.

**Architecture:** Spec: `docs/superpowers/specs/2026-10-15-kontakt-design.md`.
- **`src/contact.ts`** (pure): the links, the Poland rule and the support address by country.
- **`components/Contact.tsx`:** the list, shared by the sheet and Ustawienia, and the sheet itself.
- **`TopBar`:** gets the „@” button.
- **`Support.tsx`:** uses the same support rule.

**Tech Stack:** React 19, TypeScript 6, Vitest 5 + Testing Library (jsdom).
