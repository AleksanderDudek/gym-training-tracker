# Selgros products — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
> Executed inline in the planning session (the user is away and asked for an autonomous finish).

**Goal:** Selgros's food products with nutrition, allergens and shelf prices in the product base,
as a store you walk into.

**Architecture:** Spec: `docs/superpowers/specs/2026-10-16-selgros-design.md`. A Playwright crawler
(`scripts/food/fetch-selgros.ts`) reads the product finder's own data and writes
`src/food/chains/data/selgros.json`. The app merges it at load time by EAN (`src/food/chains/merge.ts`),
in the same chunk as the online shops' data.

**Tech Stack:** Playwright 1.63, tsx, React 19, Vitest 5.
